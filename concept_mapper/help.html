GETTING STARTED

Build your ideas into a map

Start with the central idea, add connected concepts, and switch between the visual map and a structured outline at any time. Both views show the same content.

Try an example map

The Newton's Laws example demonstrates nested topics, labeled connections, rich notes, and ideas that export as Word heading levels.

Download Newton's Laws example

After downloading, return to Concept Mapper, choose Load, and select newtons-laws-example.json from your Downloads folder. Loading it replaces the map currently open.

Try switching between Map and Outline, opening a connection label, and editing a concept's notes to explore the example.

Create and arrange concepts

  • Select a concept, then choose Add child to create a concept below it or Add sibling to add one beside it. The central idea can have children but not siblings.
  • Double-click a concept, choose Edit text, or press F2 to edit its heading and notes.
  • Edit a concept's Connection label to describe how it relates to its parent, such as depends on or reduces. The label appears on the map connector and above the concept heading in Outline and Word export.
  • In Map view, click a connector line or its label to open a small connection-label dialog. You can also focus the connector with Tab and press Enter or Space. The same label is available in the full concept editor.
  • Use Tab to add a child and Enter to add a sibling. From the central idea, Enter adds its first child.
  • In Outline, use the four arrow buttons beside Delete to move the selected concept: ↑ and ↓ reorder it among its siblings, while ← decreases its indent and → makes it a child of the previous sibling. Each move carries the whole branch. You can also drag a topic by its handle; drop it above or below another topic to reorder it, or onto a topic to make it a child.
  • Use the outline disclosure control to collapse or expand a branch. Map view offers zoom, pan, and Fit map controls.
  • In Map view, choose Balanced to spread first-level branches across both sides of the central idea, or Right aligned to place the central idea on the left and grow all branches to the right. Your choice is remembered in this browser.
  • Use Undo and Redo or Ctrl/Cmd + Z to step through changes. Select a non-central concept and choose Delete to remove its branch.

Add notes to a concept

Each concept has a short Heading and a separate Notes area. Put supporting detail, evidence, or context in Notes. Notes appear below headings in Outline and are indicated on map concepts.

The notes toolbar provides Bold, Italic, bulleted and numbered lists, superscript, subscript, a right arrow (→), and equilibrium arrows (⇌). The arrow controls insert the symbol at the cursor, or replace selected text. Select text before applying a format; to start a list, place the cursor in a paragraph and choose the bullet or numbered-list control. Select superscript or subscript text and choose Normal text (the plain x button) to return it to the baseline while keeping other formatting. With no selection, the control returns typing to the baseline.

Save and load map files

Maps are kept in browser storage as a recovery copy. Use Save As to create a portable JSON map file. In current Edge and Chrome, choosing a file links it to this browser profile and edits autosave to it. The status beside the file controls shows when a save is in progress or complete.

  • Choose Load to open and link an existing Concept Mapper JSON file. Loading a different map replaces the one currently open.
  • If the linked file changes outside the app, editing pauses to protect those changes. Choose Reload to load the latest file contents.
  • After a cloud drive finishes syncing on another device, choose Reload to bring the latest file into the app.
  • Choose New to start a blank map. If there are pending edits to a linked file, the app saves them when possible and disconnects that file before starting over.
  • If your browser does not support linked files, Save As downloads a JSON copy and Load imports one. After further edits, download another copy to keep the file current.

Keep your downloaded JSON files somewhere you can find them; they contain the map headings, notes, and structure.

Export your work

  • Export image downloads the map as an SVG image that can be opened or placed in other documents.
  • Export Word creates a Word document with narrow 1.27 cm margins. The central idea is Heading 1, its children are Heading 2, and each deeper concept uses the next heading level. The document includes Word Heading 1–9 styles and uses the Word theme font. Connection labels appear immediately before their concept heading. Notes follow their concept heading and retain supported formatting.

Exports create a separate copy; they do not change the linked JSON map file.

More features will be added over time. Return to your map whenever you are ready.
