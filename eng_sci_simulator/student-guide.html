QLQUAKELAB

Student guide

Design → Build → Shake → Measure → Improve

Design a simplified structure, test it on an earthquake shake table, measure its response, identify weaknesses and improve it. Keep the earthquake settings unchanged when comparing designs.

1 Foundation2 Frame3 Materials4 Mass5 Sensors6 Earthquake7 Test8 Results9 Improve
1

Build a foundation

  1. Select Floor Joint or press G.
  2. Tap twice to create two foundation joints. They automatically appear on the solid ground line.
  3. Check for lime-green centres. These joints are fixed to the shake table.
  4. Select Joint or press J and place movable joints above the foundations.
2

Connect the structure

  1. Select Beam (B) or Brace (R).
  2. Press on the first joint, drag to the second joint and release directly over it.
  3. Add vertical columns and horizontal beams.
  4. Try diagonal bracing. Triangular arrangements usually resist sideways movement better than unbraced rectangles.

Important: Beams must end on joints. A joint placed visually over an existing beam does not split that member.

3

Select materials

Choose timber, steel, reinforced or lightweight before drawing new members. Compare the displayed classroom values:

  • Strength
  • Stiffness
  • Weight
  • Damping
  • Cost per metre-equivalent

Changing material affects new members only—not members already drawn.

4

Add payload masses

  1. Select Mass or press M.
  2. Tap a joint or any position along a member.
  3. Tap an existing mass to open its editor.
  4. Adjust it in 100 kg steps, enter 100–5,000 kg, or remove it.

A beam mass is distributed between its endpoint joints according to position. It does not create an extra hinge.

5

Add analysis sensors

  1. Select Sensors or press S.
  2. Tap up to four joints or positions along members.
  3. Each sensor is labelled S1–S4 and appears under Live Measurements.
  4. Select a sensor from the graph menu to display its response.
  5. Use × on its live card to remove it.

Sensors report signed horizontal displacement relative to the moving table: positive is right and negative is left.

6

Configure the earthquake

Amplitude
Maximum shake-table displacement.
Frequency
Cycles per second. Frequency has a squared effect on peak acceleration.
Duration
Length of the test.
Structural damping
Simplified energy loss in the model.

Peak acceleration is calculated using a = (2πf)²A and displayed relative to gravitational acceleration.

7

Run the test

  1. Check structure cost, member count and total mass.
  2. Select Start test.
  3. Observe roof sway, storey drift, failures, acceleration, sensor readings and the response graph.
  4. Use Pause, Resume or Reset when needed.

Red member with !: the beam or brace has exceeded its simplified material deformation limit and failed. It stops carrying load for the rest of that test. Loading colours are classroom indicators, not professional stress calculations.

8

Interpret survival

The structure survives only when all four classroom limits are satisfied:

MeasurementSurvival limit
Maximum roof sway≤ 160 mm
Maximum relative storey drift≤ 80 mm
Failed members≤ 25%
Height retained≥ 65%

The results identify any limit that caused failure.

9

Modify and retest

Close the results to return to editable Design Mode. Consider changing:

  • Bracing pattern
  • Member material
  • Structure width or height
  • Payload position or mass
  • Number and position of members

Fair test: keep the same earthquake settings when comparing two designs.

Troubleshooting

The structure falls immediately
Check that columns connect to Floor Joints.
A loose joint falls
Connect it with members before testing.
A beam will not appear
Drag from one joint and release directly over another.
A mass cannot be edited
Select Mass, then tap the mass label.
A sensor shows zero
Check its attachment and select the correct sensor in the graph.
The design cannot be edited after testing
Close the results window to return to Design Mode.
