Lesson Sequence Board Help

Back to board

Use Lesson Sequence Board to arrange lesson ideas across weeks and lesson slots. Your work stays on this device unless you explicitly save or export it.

Start a board

  1. Choose the number of Weeks and Lessons per week.
  2. Select Create Board. If a board already exists, this becomes Reset Board and asks for confirmation before replacing it.
  3. Select Add lesson in an empty slot to begin planning.

Edit and organise lessons

  • Type a lesson title and a short description directly into a lesson card. Changes save automatically in this browser.
  • Use the + button between cards to insert a lesson after a selected lesson.
  • Drag a lesson by its handle. Drop it on the blue left-edge target of another card to place it before that lesson.
  • Drag the dotted line beneath a week label to resize that week. Double-click the line to restore its default height.
  • Select the bin button in a lesson card to delete that lesson.

Manage the board

  • Add Week appends a new week with the current number of lesson slots.
  • Clear removes the saved board from this browser after confirmation.
  • Dark mode switches the colour theme. The preference is remembered on this device.

Save, load, and export

  • Save creates a full JSON copy of the board. In Chrome and Edge, choosing a file once enables automatic updates to that selected file. Use Save As to choose a different filename or location; that file then becomes the automatic save file.
  • Load restores a compatible JSON board file and replaces the current board after confirmation.
  • Export Excel downloads a formatted workbook with weeks as rows and lesson slots as columns.

Tip: Use Save before clearing browser data, changing browsers, or moving to another device.

Privacy and offline use

The board has no account, server, or external service. It works offline and stores automatic saves in this browser. Save a JSON file when you need a portable backup.
