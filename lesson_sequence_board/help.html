LESSON SEQUENCE BOARD

Help and guidance

Back to board

Use Lesson Sequence Board to arrange lessons across weeks and lesson slots. Link a JSON file to save changes automatically, or download a JSON or Excel copy when you need one.

Try the example board

New to the board? The example contains a complete Year 10 Science motion unit with 24 lessons across six weeks. Right-click the link and choose Save link as…, then use Load on the board to open the saved JSON file.

Year 10 Science motion demo (.json)

Start a board

  1. Choose the number of Weeks and Lessons per week.
  2. Select Create Board. If a board already exists, this becomes Reset Board and asks for confirmation before replacing it.
  3. Select Add lesson in an empty slot to begin planning.

Edit and organise lessons

  • Select a lesson card to open its editor. Edit the title and description, then select Save lesson; Cancel, Escape, or clicking outside the dialog discards unsaved edits. Saved text appears on the card and auto-saves to a linked JSON file. If no file is linked, use Save As to keep changes.
  • Each lesson card shows its bold title below the lesson number. Use the + control in the top-right of a lesson cell to insert a lesson after it, or − to delete that lesson.
  • Drag any part of a lesson card to move it. Drop on the teal left-edge target of another card to place the lesson before it.
  • Week rows automatically fit the tallest lesson in that week, leaving about one text line beneath the content. Drag the dotted line beneath a week label to set a custom height; double-click it to return to automatic sizing.

Manage the board

  • Add Week appends a new week with the current number of lesson slots.
  • New starts a blank board and disconnects the current JSON file. Pending changes are saved when possible; confirm before leaving unsaved changes behind.
  • Clear removes all lessons from the current board after confirmation. If a JSON file is linked, the cleared board auto-saves to it.
  • Undo and Redo reverse or restore up to 100 board changes. You can also use Ctrl+Z / Cmd+Z to undo and Ctrl+Y / Cmd+Shift+Z to redo. Shortcuts are ignored while typing in a text field.

Save, load, and export

  • Save As chooses a JSON file and makes it the automatic save file in supported Chrome and Edge browsers. Later board changes auto-save to that file.
  • Load opens a compatible JSON board file and replaces the current board. In supported browsers, the loaded file becomes the automatic save file. If unsaved changes are present, you’ll be asked before they are replaced.
  • If browser file access is unavailable, Save As downloads a JSON copy and Load imports a copy. Changes after import need another download; ongoing file auto-save is unavailable in that browser.
  • Export Excel downloads a dated, formatted workbook with weeks as rows and lesson slots as columns. It does not change the JSON board file.

Tip: Keep the linked JSON file in a synced folder if you use the board on more than one computer. The board checks for outside file changes before saving and asks you to reload if the file changed.

Privacy and offline use

The board has no account, server, or external service. It works offline. The linked JSON file is the source of truth, while the browser remembers its local file handle. Excel exports are separate copies.
