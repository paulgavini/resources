Weekly Planner Help

This guide explains the planner in simple steps. Your planner is kept in a .json file. Keep that file somewhere you can find it, such as your approved OneDrive folder.

Want to use the example planner? Use the right mouse button on this link: 2026 four-term demonstration planner (.json). Choose Save link as… from the menu and save the file to your computer. Then return to the planner, choose Load, and select the file you saved.

Start with a planner

  1. Save As makes a new planner file. Choose a folder you can find again. The app remembers the file in this browser and saves your changes to it.
  2. Load opens a planner file you already have. Choose the .json file when asked.
  3. New starts a blank planner with four terms. It asks before replacing the planner currently on screen. Save a copy first if you want to keep the current planner separately.
  4. Export Excel downloads an .xlsx workbook with one sheet per term. Each lesson and day note has its own row, with dates, lesson order, and notes. Exporting does not change your planner file.

Look at the message beside the green dot in the top right. It shows which file is connected and when it was last saved. A green dot means the last save completed.

Use the same planner on another computer

  1. Keep your .json planner file in a cloud-synced folder, such as OneDrive, if your organisation allows it.
  2. On the other computer, open the planner page and select Load. Choose the same .json file. Allow the browser to access it if asked.
  3. When returning to a computer, wait until the cloud service has finished syncing. Refresh the planner page, then use Reload if it is offered. Check that the correct file name appears before editing.

Each computer may ask you to choose or allow access to the file. If the browser says another copy of the file changed, reload the latest copy before continuing. Avoid editing the same planner on two computers at the same time, as one computer's later save could replace the other's changes.

For ongoing automatic saving to a chosen file, use a recent version of Chrome or Microsoft Edge. If the browser only downloads a file or asks you to choose a file each time, use Save As to download a copy and Load to open it again. In that mode, save and keep the downloaded copy yourself.

Terms, dates, and weeks

  • Select Term 1, Term 2, Term 3, or Term 4 across the top. Each term has its own subjects and timetable.
  • Choose the term's starting Monday using Term starts on. The planner dates then run Monday to Friday. Days before today have a different background colour.
  • Use + to add a week at the end. Use − to remove the last week. At least one week stays in the term.
  • Use Undo and Redo beside the week controls to reverse or restore up to 100 recent planner changes. Keyboard shortcuts are Ctrl+Z and Ctrl+Y on Windows, or Command+Z and Command+Shift+Z on Mac. Loading a planner or starting New clears the undo history.

Add or change subjects

  1. Open Manage subjects.
  2. Type the subject name, for example “10 Connect”.
  3. Select every weekday when it is taught, then choose Add subject.

The planner places that subject on the selected weekdays in each week. Add it separately in each term where it is taught, or copy another term's schedule using the instructions below. Use the subject list to change its name, weekdays, or remove it.

To reuse a schedule, choose Copy subjects and weekday order from and select another term, then choose Copy schedule. This copies recurring subjects and weekday order only. It replaces the current term's subjects, lessons, one-off lesson moves, and lesson notes. It keeps the current term's start date, number of weeks, and day notes. The planner asks you to confirm first.

Move lessons and change their order

  • Drag a lesson to another weekday to move just that lesson occurrence.
  • Drag a lesson up or down within its weekday to change the usual order for that weekday across every week in the selected term.
  • Select a lesson to open its notes. Type or change the notes and choose Save notes. Lesson notes belong to that lesson in that week.

Add a note to a day

Choose the small + inside a day to add a separate note for that date. You can drag a day note to another day, or drag it up and down to choose where it sits among that day's lessons. A day note is separate from lesson notes.

Use the small box on the right side of a day note to mark it complete. A tick appears when it is checked. Click it again to mark the note incomplete.

Quick fixes

  • No file linked: choose Save As to create a file, or Load to open an existing one.
  • Browser asks for file access: allow access to the selected file so the planner can read and save it. If access was removed, choose Load again.
  • Changes are missing on another computer: wait for OneDrive or your cloud service to finish syncing, then refresh the planner and load or reload the file.
  • File will not load: confirm you selected the planner .json file, not the planner web page. Keep a backup copy before making large changes.
