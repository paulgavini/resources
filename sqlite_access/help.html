Help and getting started

Explore a local SQLite database, build queries, and learn how the workspace saves your changes.

PRACTICE DATABASE

Try the school demo

Download the example database to experiment with students, courses, and enrollments. It includes two relationships linking enrollments to students and courses.

Download school demo database

In DataNook, choose Open database and select the downloaded school-demo.sqlite file.

Browse and edit data

Choose a table in the left navigation, then use Datasheet to view and edit its rows. Use the arrow beside a field heading to search its distinct values, select which values to show, and apply a filter. Filters can be combined across fields and change only the displayed rows. Paste tab-separated cells copied from a spreadsheet to add or update multiple values. Changes save automatically.

Create tables and import files

Use Table Designer to create a table and set each field’s name, SQLite data type, primary key, and constraints. In Datasheet, click a field heading to open Table Designer. Choose Cancel to discard unsaved design edits and return to Datasheet. In Datasheet, choose the red × Delete button beside the selected table to delete it and its records after confirmation; remove incoming relationships first. Choose Import CSV as table in Table Designer to preview a CSV or TSV file and create a new table from it; the first row is used for field names by default.

Explore relationships and queries

Relationships shows linked fields between tables. Query Design lets you add related tables, choose fields, sort and filter results, calculate values with a named expression, and calculate totals such as counts and averages. Calculated fields appear in query results without being added to a table. Add a field more than once to use each instance separately, such as grouping by a label and summing a numeric value. Drag rows in the query grid to change the output column order, or focus a row and use Alt+Up/Down. SQL Editor runs SQLite statements and offers table and field suggestions.

Save and move databases

The workspace runs in your browser. It saves changes in the current browser profile. Use Save as to keep a portable SQLite file, or Open database to work with an existing .sqlite, .sqlite3, or .db file.

Create reports

Reports can use related table fields or the latest SQL Editor results. Select fields, choose grouping and sorting options, and generate a preview. Use Save report, Load, and Delete to manage report setups saved inside the database file. Query based reports save their SQL and ask you to run it again when loaded. Use Print to print or save a PDF, or export the preview as an Excel .xlsx workbook or Word .docx document.

Browser requirements

SQLite runs locally in a Chromium based browser using WebAssembly. An internet connection is needed to load the SQLite engine and document export libraries when opening the app. File saving options depend on the browser; browser storage remains available for automatic saves.
