Help and getting started

Explore a local SQLite database, build queries, and learn how the workspace saves your changes.

PRACTICE DATABASE

Try the school demo

Download the example database to experiment with students, courses, and enrollments. It includes two relationships linking enrollments to students and courses.

Download school demo database

In DataNook, choose Open database and select the downloaded school-demo.sqlite file.

Browse and edit data

Choose a table in the left navigation, then use Datasheet to view and edit its rows. Paste tab-separated cells copied from a spreadsheet to add or update multiple values. Changes save automatically.

Create tables and import files

Use Table Designer to create a table and set each field’s name, SQLite data type, primary key, and constraints. Choose Import CSV as table there to preview a CSV or TSV file and create a new table from it; the first row is used for field names by default.

Explore relationships and queries

Relationships shows linked fields between tables. Query Design lets you add related tables, choose fields, sort and filter results, and calculate totals such as counts and averages. SQL Editor runs SQLite statements and offers table and field suggestions.

Save and move databases

The workspace runs in your browser. It saves changes in the current browser profile. Use Save as to keep a portable SQLite file, or Open database to work with an existing .sqlite, .sqlite3, or .db file.

Create reports

Reports can use related table fields or the latest SQL Editor results. Select fields, choose grouping and sorting options, preview the report, and use your browser’s print dialog to print or save it as a PDF.

Browser requirements

SQLite runs locally in a Chromium based browser using WebAssembly. An internet connection is needed to load the SQLite engine library when opening the app. File saving options depend on the browser; browser storage remains available for automatic saves.
